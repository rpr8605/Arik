# Completeness audits

Arik's completeness audits live in this folder: one file per audit named
`AUDIT_YYYY-MM-DD.md`, using the template in section 9 of
`ARIK_MASTER_SPEC.md`. Each audit scores every module acceptance criterion
(DONE / PARTIAL / MISSING / UNVERIFIED, with evidence) and recomputes the
stage gates S1 to S7.
