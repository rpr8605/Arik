# Code review (CODE_REVIEW_AND_DOCS.md, Part A)

Findings only; nothing here is fixed yet. Ryan decides which to fix; each
fix lands in its own session with a test that would have caught it.

Severity: **Critical** = wrong money, data leak or security hole.
**High** = wrong result or crash a user can hit. **Medium** = fragile
code or a missing test on important logic. **Low** = cleanup.
Size: S = under an hour, M = about a session, L = more.
